# 数据存储与隐私

糖果磁链在 Mac 本机读取 `.torrent` 文件并生成磁力链接。应用没有账号、云端存储、遥测或在线更新功能。

## 种子与转换结果

导入的种子在应用运行期间被读取，用于解析元数据、计算文件指纹和生成链接。原始种子不会复制到应用历史目录；文件路径用于当前窗口展示，不写入历史数据库。

每次点击转换，包括单条重新转换，都会保存一个独立批次：

| 数据 | 内容 |
| --- | --- |
| 批次标识与时间 | 批次唯一标识及开始时间 |
| 批次统计 | 文件数、成功数、失败数和链接数 |
| 转换结果 | 按原顺序保存的名称、完整磁力链接及记录标识 |

“包含文件名称”和“保留 Tracker”决定磁力链接中的 `dn`、`tr` 参数。名称会独立保存；关闭“包含文件名称”只影响链接本身。历史保留转换时的链接，之后修改选项不会改写旧记录。

旧版本保存的逐文件记录保留名称、链接与原始转换时间，在历史窗口中显示为“旧版记录（批次未知）”。应用不会根据记录时间猜测原始批次。

## 操作记录

应用保存转换、奇数行复制、偶数行复制、全部复制、单条复制、导入、清空列表、移除文件以及名称和 Tracker 选项变更。历史窗口中的单条复制也会保存操作记录。

每条操作记录包含唯一标识、发生时间、数量、结果和详情。详情可能包括文件名、选择的选项与涉及的批次数。属于单一批次的操作可关联该批次，跨批次复制不归入某一个批次。

操作记录仅保存在本机，不包含完整文件路径，也不读取或保存任意系统剪贴板内容。复制成功但操作记录保存失败时，界面分别提示，并提供补存记录的重试入口。

## 保存位置与期限

历史数据库位于：

```text
~/Library/Application Support/糖果磁链/history.sqlite3
```

SQLite 使用 WAL 模式，运行时同目录中可能存在 `history.sqlite3-wal` 和 `history.sqlite3-shm` 文件。

历史保留最近 `7 × 24` 小时。转换批次按开始时间（`startedAt`）整批保留和清理，操作记录按发生时间（`createdAt`）计算，旧版逐文件记录按原始转换时间计算。应用在启动、历史读写及运行期间的定时维护中删除过期记录。应用退出后不运行后台清理进程，下次打开时继续清理。

关闭窗口、清空当前文件队列或替换应用包，都不会主动删除仍在保留期内的历史。卸载 `.app` 也不会删除 Application Support 中的数据。

## 网络与剪贴板

App 内部资源服务只监听本机回环地址和动态端口，用于加载随应用打包的界面、脚本和字体。转换过程不连接 Tracker 或 DHT，不下载种子对应内容，也不向远程服务器发送种子或历史记录。

点击复制会将链接写入 macOS 系统剪贴板。剪贴板内容由系统和用户安装的剪贴板工具管理，不随应用历史过期自动清除。

## 清除本地数据

退出糖果磁链，在 Finder 的“前往文件夹”中打开 `~/Library/Application Support/糖果磁链/`，删除该目录即可清除全部本地历史。该操作不可恢复；重新打开应用后会创建空数据库。

仓库的忽略规则排除种子文件、SQLite 数据库、日志和构建产物，上传的源码不包含个人转换历史。
