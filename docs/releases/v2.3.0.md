# 糖果磁链 v2.3.0

磁力链接区域随窗口伸展，转换历史按每次点击归档为独立批次，历史窗口新增操作记录与保存失败重试。

## 下载与安装

[下载 CandyMagnet-2.3.0-macOS-arm64.zip](https://github.com/NeverOvO/candy-magnet/releases/download/v2.3.0/CandyMagnet-2.3.0-macOS-arm64.zip)

- 设备：Apple Silicon Mac，arm64 架构。
- 系统：macOS 12.0 及更新版本。
- 应用版本：2.3.0，构建号 8。

下载并解压 ZIP，将“糖果磁链.app”拖入“应用程序”文件夹，双击打开即可使用。

## 更新内容

- 主窗口磁力链接面板和文本框填满剩余空间，小窗口保留最小高度并支持滚动。
- 每次点击转换，包括单条重新转换，形成独立批次，保存时间、文件数、成功数、失败数和链接数。批次列表每页 50 批，展开后按原顺序查看链接，每页 100 条。
- 历史窗口可切换“转换批次”和“操作记录”，查看转换、各类复制、导入、清空列表、移除文件及选项变更的时间、数量、结果和详情。跨批次复制记录涉及的批次数，历史窗口内的单条复制也会记录。

复制成功但操作记录保存失败时，界面分别提示复制结果和保存错误，并可重试补存记录。重试沿用原标识，不重复保存，也不重复执行复制。

## 从旧版本更新

退出糖果磁链，使用新应用替换“应用程序”文件夹中的旧版本，再次打开。已保存的历史位于 `~/Library/Application Support/糖果磁链/history.sqlite3`，替换应用不会清空尚在保留期内的记录。旧版逐文件记录显示为“旧版记录（批次未知）”，保留原始转换时间。

历史保留最近 7 × 24 小时：新批次按开始时间整批清理，操作记录按发生时间清理，旧版记录按原始转换时间逐条清理。主窗口的文件队列和未保存的历史不会跨退出恢复；窗口显示保存失败时，先完成保存再退出。
