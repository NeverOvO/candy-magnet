# 糖果磁链 v2.2.0

本次更新更换为糖果玻璃磁铁应用图标，提供 Apple Silicon 安装包。种子转换、复制和最近 7 天历史记录的使用方式保持不变。

## 下载与安装

[下载 CandyMagnet-2.2.0-macOS-arm64.zip](https://github.com/NeverOvO/candy-magnet/releases/download/v2.2.0/CandyMagnet-2.2.0-macOS-arm64.zip)

- 设备：Apple Silicon Mac，arm64 架构。
- 系统：macOS 12.0 及更新版本。
- 应用版本：2.2.0，构建号 5。

下载并解压 ZIP，将“糖果磁链.app”拖入“应用程序”文件夹，双击打开即可使用。应用包含所需的界面资源，不需要安装 Node.js 或手动启动服务。

## 更新内容

- 更换糖果玻璃磁铁应用图标，沿用薄荷绿、蜜桃粉与淡紫色配色。
- 保存图标源 PNG、画面方案和完整生成提示词；构建时将源 PNG 转换为 macOS 图标尺寸。
- 应用包包含项目许可证、第三方声明和许可文本。
- 补全下载、安装及版本更新说明。

## 从旧版本更新

退出糖果磁链，使用新应用替换“应用程序”文件夹中的旧版本，再次打开。已保存的历史位于 `~/Library/Application Support/糖果磁链/history.sqlite3`，替换应用不会清空尚在保留期内的记录。

历史继续按转换时间保留最近 7 × 24 小时，过期记录自动清理。主窗口的文件队列和未保存的记录不会跨退出恢复；窗口显示“重试保存历史”时，先完成保存再退出。

## 签名状态

该安装包使用 ad hoc 本地签名，没有 Developer ID 签名，也未经过 Apple 公证。macOS 对下载的应用可能显示安全提示。源码构建方式见[项目 README](https://github.com/NeverOvO/candy-magnet/blob/v2.2.0/README.md#从源码构建)。
